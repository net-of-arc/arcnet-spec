# supports

**Positive stance.** The citing work provides support for statements, ideas or conclusions in the target — it agrees with, confirms, or builds on them. One predicate for every positive CITO intent (`citesAsEvidence`, `citesAsAuthority`, `confirms`, `extends`); a domain needing the finer distinction registers it in its own bundle.
