# replaces

**Supersession over time.** `X replaces:: Y` asserts `X` supplants an older `Y` (`Y` obsolete in favour of `X`). Use for versions and standards that succeed one another. *e.g.* `Transport Layer Security` → `replaces::` `SSL Protocol`.
