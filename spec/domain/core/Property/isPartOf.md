# isPartOf

**Composition (part–whole).** `X isPartOf:: Y` asserts `X` is a component or member of the whole `Y`. Mereology, not "is a kind of" (that is `broader`). *e.g.* `Certificate Transparency` → `isPartOf::` `Audit Log`.
