# description

A statement **about** the subject — what it is, mostly a definition — as opposed to `text`, the content the subject carries. Single-valued: the first accepted definition stands and a divergent one is reported for review, because a definition that grows by appending turns into an essay. The body prose of every `Property` and `Class` node.
